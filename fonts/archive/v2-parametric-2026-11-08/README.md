# Archived: v2.0 parametric rebuild experiment (2026-11-08)

These files were generated by the agent as a normalized parametric rebuild of the
hand-drawn font (uniform stroke 100, baseline at 0, aligned metrics, monospace 648).
They are NOT the official font — the letterforms deviated from the hand-drawn
originals, especially the curved glyphs (a, o), and were reverted the same day.

The official font remains the hand-drawn original at `fonts/susedifu.ttf` /
`fonts/susedifu.svg` (see git history for every version).

Contents:
- `susedifu-v2-parametric.ttf` — the compiled experiment font
- `susedifu-v2-parametric.svg` — its stroke-based design source
- `SPEC.md` — the experiment's metric specification
